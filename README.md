# КАПІТАЛ — Персональний трекер інвестиційного портфеля (UAH / USD)

Вебзастосунок для ведення власних інвестицій у різних класах активів з одночасним відображенням вартості у **Гривні (₴ UAH)** та **Доларах США ($ USD)**.

## Основні можливості

1. **Загальна картина портфеля (`Всі активи`)**:
   - Миттєвий підрахунок загального капіталу в `₴ UAH` та `$ USD`.
   - Сукупний прибуток (`PnL`) з урахуванням зростання вартості активів та вже накопичених відсотків за облігаціями/депозитами.
   - Інтерактивна діаграма розподілу за класами активів та валютна структура портфеля (`USD`, `UAH`, `EUR`).
2. **Криптовалюта (`crypto`)**:
   - Поточні позиції (кількість + середня ціна купівлі в `$`).
   - Автоматичне підтягування ринкових цін з **Binance API** та **CoinGecko**.
3. **Фондовий ринок (`stocks`)**:
   - Акції США та світові індексні ETF (`VOO`, `SPY`, `VWCE`, `CSP1`, `QQQ`, `NVDA`, `AAPL` тощо).
   - Автоматичне оновлення котирувань через серверний фід **Yahoo Finance**.
4. **ОВДП (`ovdp`)**:
   - Підтримка гривневих та валютних (`USD`, `EUR`) військових і державних облігацій.
   - Автоматичний розрахунок вже накопиченого доходу станом на сьогодні за `% річних` без оподаткування (`0% податків`).
5. **Банківські депозити (`deposits`)**:
   - Автоматичний розрахунок нарахованих відсотків за ставкою `% річних` з можливістю автоматичного вирахування податків (`18% ПДФО + 5% ВЗ = 23%`) або чистої ставки.
6. **Готівка та поточні рахунки (`cash`)**:
   - Облік готівки у сейфі, на картках або рахунках (`USD`, `UAH`, `EUR`, `GBP`, `PLN`) з автоконвертацією за курсом НБУ або власним фіксованим курсом.
7. **Персональний захист паролем**:
   - У розділі **«⚙ Налаштування та Пароль»** можна увімкнути вхід за паролем власника (за замовчуванням: `admin123` або змінна середовища `PORTFOLIO_PASSWORD`).

---

## Як запустити локально

```bash
node server.js
```

Сервер запуститься на `http://localhost:3000`. Жодних зовнішніх `npm` пакетів встановлювати не потрібно — застосунок працює на чистому вбудованому стеку Node.js.

## Як захостити в Інтернеті (3 простих варіанти)

### Варіант 1: Render.com (Безкоштовно)
1. Завантажте папку `portfolio-tracker` у приватний репозиторій на **GitHub**.
2. Зайдіть на [Render.com](https://render.com) → **New +** → **Web Service** (або **Blueprint**, оскільки у проєкті вже є готовий файл `render.yaml`).
3. Підключіть репозиторій:
   - **Build Command**: залиште порожнім
   - **Start Command**: `node server.js`
   - У розділі **Environment Variables** додайте `PORTFOLIO_PASSWORD` зі своїм паролем.
4. Натисніть **Deploy** — за 1 хвилину ви отримаєте постійне HTTPS-посилання виду `https://kapital-tracker.onrender.com`.

### Варіант 2: Railway.app або Fly.io (З постійним диском)
1. Зайдіть на [Railway.app](https://railway.app) → **New Project** → **Deploy from GitHub repo**.
2. Railway автоматично підхопить конфігурацію з `railway.json` та `Dockerfile`.
3. Додайте Volume (монтування в `/app/data`), щоб файл `data/portfolio.json` зберігався між перезапусками контейнера.

### Варіант 3: Будь-який VPS з Docker
```bash
docker build -t kapital-tracker .
docker run -d -p 3000:3000 -v $(pwd)/data:/app/data -e PORTFOLIO_PASSWORD="мій_надійний_пароль" --name kapital kapital-tracker
```
